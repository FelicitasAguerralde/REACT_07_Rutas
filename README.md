# React router

Instalar el paquete: npm install react-router-dom
Crear la carpeta routes y el archivo Routes.js
Importar: import {Routes, Route, Link, BrowserRouter} from 'react-router-dom';

## Boostrap
Instalar la librería: npm install react-bootstrap bootstrap
Importar estilos: import 'bootstrap/dist/css/bootstrap.min.css';
